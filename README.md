# Uzbekistan Club - Clone

## Project Overview

Uzbekistan Club is a modern website built using React JS, designed to showcase the beauty and culture of Uzbekistan. The website features a clean, responsive design with a focus on user experience and smooth navigation.

## Key Features

- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices. ❌
- **Dynamic Components**: Developed using React JS for better performance and component-based architecture.
- **Interactive UI**: Includes various interactive elements like sliders, animations, and hover effects.
- **Modern Technologies**: Built with the latest web development tools, including CSS modules and React Router for smooth transitions.

## Tech Stack

- **Frontend**: React JS, JS,
- **State Management**: React hooks
- **Routing**: React Router
- **Styling**: Tailwind CSS 
- **Version Control**: Git

## How to Run Locally

1. Clone the repository:
    ```bash
    git clone https://github.com/username/uzbekistan-club.git
    ```
2. Navigate to the project directory:
    ```bash
    cd uzbekistan-club
    ```
3. Install dependencies:
    ```bash
    npm install
    ```
4. Start the development server:
    ```bash
    npm start
    ```

The website will be accessible at `http://localhost:5173`.
